# HOLLOO PRO+

اپلیکیشن مستقل حسابداری و مدیریت انبار برای اندروید؛ با تمرکز بر فروش و واردات نخ.

## وضعیت نسخه
نسخه 0.2.0 یک MVP در حال توسعه است و نرم‌افزار کامل هلو یا محصول حسابداری تأییدشده محسوب نمی‌شود. قبل از استفاده عملیاتی، آزمون میدانی، کنترل مالی و بازبینی حسابدار لازم است.

## امکانات پیاده‌سازی‌شده در این شاخه
- رابط فارسی RTL با تم سرمه‌ای و جزئیات فیروزه‌ای و نوار پایین.
- پایگاه داده آفلاین Room و migration نسخه 1 به 2.
- مدل کالاهای نخ با کد یکتا، گروه، نوع نخ، رنگ، دنیر، تاب‌دار/بدون‌تاب و واحد کیلوگرم.
- گردش موجودی ورود/خروج از طریق فاکتور خرید و فروش و کنترل موجودی منفی.
- اشخاص مشتری/تأمین‌کننده و دفتر گردش بدهکار/بستانکار.
- فاکتور تک‌ردیفی خرید/فروش، تخفیف، مالیات، ثبت و برگشت.
- صدور سند دوبل متوازن برای فاکتور و ثبت دریافت از مشتری/پرداخت به تأمین‌کننده از صندوق یا بانک.
- سفارش واردات با USD/CNY/IRR، نرخ تبدیل، کانتینر، وزن، هزینه حمل/گمرک/سایر و سررسید تأمین‌کننده.
- محاسبه بهای تمام‌شده ریالی هر کیلو.
- تست‌های واحد برای تراز سند، دریافت/پرداخت صندوق و بانک، تبدیل ریال/تومان و بهای تمام‌شده.

## ساخت
با JDK 17، Android SDK 35 و Gradle 8.9:
```bash
gradle testDebugUnitTest assembleDebug --no-daemon
```

خروجی debug در مسیر `app/build/outputs/apk/debug/app-debug.apk` خواهد بود.
