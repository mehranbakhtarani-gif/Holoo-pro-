# HOLLOO PRO+ PWA

نسخه وب فارسی و راست‌چین، قابل نصب و دارای ذخیره‌سازی آفلاین با IndexedDB.

## اجرا و انتشار
برای تست محلی، پوشه `pwa` را با وب‌سرور static روی HTTPS یا localhost اجرا کنید؛ اجرای مستقیم با `file://` برای Service Worker مناسب نیست. انتشار GitHub Pages از workflow مستقل انجام می‌شود و Source مخزن باید روی GitHub Actions باشد.

## قابلیت‌های موجود در این شاخه
- داشبورد، کالاها، اشخاص، فاکتورهای خرید و فروش چندردیفی، کنترل موجودی و بهای تمام‌شده ساده
- دفتر حساب‌ها، سند دستی چندردیفی، گزارش مالی، دریافت و پرداخت اتمیک با سند حسابداری، تخصیص چندمرحله‌ای تراکنش به فاکتورها، چک‌ها و اصلاح موجودی با سند حسابداری
- گزارش ممیزی پایه برای ثبت تغییرات اطلاعاتی و اسناد مالی
- سفارش واردات با ارزهای USD/CNY/EUR و هزینه‌های جانبی
- پشتیبان‌گیری و بازیابی JSON، نصب‌پذیری و کش آفلاین
- ماژول‌های پایه برای تعریف انبارها، ثبت محموله وارداتی با بهای واحد، گردش تأیید، کارکنان، حقوق و دستمزد و دارایی ثابت

## محدودیت‌ها و موارد باقی‌مانده
- ماژول انبارها فعلاً فهرست انبارها را نگه می‌دارد؛ تفکیک مقدار و ارزش موجودی در هر انبار و انتقال بین انبارها هنوز پیاده‌سازی نشده است.
- ثبت حقوق و دستمزد و دارایی ثابت فعلاً اطلاعات و محاسبات پایه را نگه می‌دارد؛ صدور خودکار اسناد حقوق، پرداخت و استهلاک دوره‌ای باید تکمیل و تست شود.
- گردش تأیید فعلاً درخواست و وضعیت را ثبت می‌کند؛ قفل‌کردن عملیات مالی تا اخذ تأیید و گردش چندمرحله‌ای اجباری هنوز تکمیل نشده است.
- تخصیص تراکنش به فاکتورها در این مرحله به‌صورت ثبت تخصیص‌های مجزا انجام می‌شود؛ بستن خودکار مانده فاکتور، کنترل تخصیص‌های برگشتی و گردش پیشرفته تسویه هنوز نیازمند تکمیل است.
- تطبیق و واردات CSV بانکی پیشرفته، مدیریت کامل محموله و هزینه‌های ارزی/تسویه و همگام‌سازی امن PWA با Android از کارهای باقی‌مانده‌اند.
- داده‌ها هنوز بین نسخه وب و اندروید همگام نمی‌شوند و روی همین مرورگر/دستگاه باقی می‌مانند. همگام‌سازی چندکاربره به API، احراز هویت، کنترل دسترسی و سیاست حل تعارض نیاز دارد.
- گزارش‌ها جایگزین بررسی حسابدار یا الزامات قانونی مالیاتی نیستند. پیش از استفاده عملیاتی، محاسبات و داده‌های نمونه را بررسی کنید.

این شاخه برای بازبینی و تکمیل بیشتر آماده می‌شود؛ تا زمان تست و انتشار موفق، نسخه عملیاتی نهایی محسوب نمی‌شود.
