# HOLLOO PRO+ PWA

نسخه وب قابل نصب (Progressive Web App) با رابط فارسی و RTL، ذخیره‌سازی آفلاین روی دستگاه با IndexedDB و پشتیبان JSON.

## اجرا
برای تست محلی، پوشه `pwa` را با یک وب‌سرور static روی HTTPS یا localhost سرو کنید. فایل را مستقیم با file:// باز نکنید؛ Service Worker و نصب PWA به secure context نیاز دارند.

## انتشار GitHub Pages
Workflow با نام `Deploy PWA to GitHub Pages` در هر push به main که فایل‌های pwa را تغییر دهد اجرا می‌شود. بعد از موفقیت، در Settings → Pages، Source باید GitHub Actions باشد.

## امکانات فعلی
- داشبورد و گزارش فروش/بهای کالای فروش‌رفته/ارزش موجودی
- ثبت کالا و انبار کیلوگرمی با کنترل کد تکراری
- ثبت مشتری و تأمین‌کننده
- فاکتور خرید و فروش تک‌ردیفی، به‌روزرسانی موجودی و میانگین موزون ساده
- ثبت سفارش واردات با USD/CNY/EUR و هزینه‌های جانبی
- مدیریت چک‌ها و سررسید
- دریافت و پرداخت و مانده طرف حساب
- پشتیبان‌گیری و بازیابی JSON
- نصب‌پذیری، پوسته تیره، کش آفلاین و طراحی واکنش‌گرا

## محدودیت مهم
این نسخه وب مستقل است و هنوز داده‌های آن با نسخه اندروید همگام نمی‌شوند. داده‌ها در مرورگر و همان دستگاه باقی می‌مانند؛ برای استفاده چندکاربره یا همگام‌سازی ابری به سرور و احراز هویت نیاز است. فعلاً گزارش مالی خلاصه مدیریتی است و دفتر کل کامل، مالیات قانونی، چندردیفی فاکتور و ثبت خودکار تسویه چک‌ها به نسخه وب منتقل نشده‌اند. قبل از استفاده عملیاتی، داده‌های نمونه و محاسبات را با حسابدار بررسی کنید.
