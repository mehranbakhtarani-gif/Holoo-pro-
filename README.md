# HOLLOO PRO+

پروژه اندرویدی حسابداری و مدیریت واردات/فروش نخ، با رابط فارسی RTL، تم سرمه‌ای شیشه‌ای و جزئیات فیروزه‌ای.

## وضعیت فعلی
این مخزن شامل نسخه پایه توسعه است؛ نه نسخه نهایی نرم‌افزار هلو و نه محصول آماده استفاده حسابداری. ماژول‌های کامل فاکتور، اشخاص، خزانه، چک، خرید خارجی، بهای تمام‌شده، گزارش‌های مالی و همگام‌سازی باید مرحله‌ای تکمیل و آزمون شوند.

## فناوری
- Kotlin، Jetpack Compose، Room/SQLite
- حداقل Android 8.0 (API 26)، هدف API 35
- مبالغ پایه به ریال ذخیره می‌شوند؛ تبدیل تومان با تقسیم بر ۱۰
- ساختار اولیه کالاهای نخ: نوع، دنیر، تاب، رنگ، انبار و مبدأ
- هسته اولیه سند دوبل با کنترل تراز

## ساخت APK
با هر push به شاخه main یا اجرای دستی workflow، GitHub Actions تست واحد و ساخت APK آزمایشی را اجرا می‌کند. فایل خروجی در بخش Actions > اجرای workflow > Artifacts با نام HOLLOO-PRO-PLUS-debug-apk قابل دریافت است.

## ساخت محلی
پوشه HOLLOO_PRO_PLUS را در Android Studio باز کنید، JDK 17 و Android SDK Platform 35 را نصب کنید و دستور `gradle testDebugUnitTest assembleDebug` را اجرا کنید.

## هشدار نسخه
APK نوع debug برای آزمایش است و امضای انتشار (release signing)، آزمون جامع حسابداری/مالیاتی و پشتیبان‌گیری امن پیش از استفاده عملیاتی لازم است.
