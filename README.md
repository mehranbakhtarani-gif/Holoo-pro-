# HOLLOO PRO+

سامانه آفلاین حسابداری و مدیریت بازرگانی نخ، با دو کلاینت Android APK و PWA. این پروژه هنوز MVP در حال توسعه است و نرم‌افزار کامل یا تأییدشده هلو محسوب نمی‌شود.

## امکانات فعلی Android
- رابط فارسی راست‌چین و پایگاه داده محلی Room با migrationهای نسخه ۱ تا ۷.
- تعریف کالاهای نخ با کد، گروه، نوع، رنگ، دنیر، تاب و واحد کیلوگرم.
- موجودی، گردش انبار، میانگین موزون، اصلاح موجودی و سند حسابداری مربوط.
- اشخاص مشتری/تأمین‌کننده و دفتر گردش بدهکار/بستانکار.
- فاکتور خرید و فروش چندردیفی، تخفیف و مالیات کل، کنترل موجودی و برگشت کامل فاکتور.
- کدینگ پایه، سند دستی چندردیفی، مانده افتتاحیه، تراز آزمایشی ۸ ستونی و دفتر گردش حساب.
- دریافت/پرداخت صندوق و بانک با سند حسابداری خودکار.
- ثبت چک و وضعیت‌های باز، تسویه، برگشتی و باطل.
- سفارش واردات ارزی، ثبت هزینه‌های حمل/گمرک/متفرقه، رسید محموله و تخصیص بهای تمام‌شده.
- پشتیبان‌گیری و بازیابی فایل SQLite با بررسی سلامت و نسخه پایگاه داده.

## امکانات فعلی PWA
- رابط فارسی راست‌چین با IndexedDB مستقل و قابلیت نصب به‌صورت PWA.
- کالا، اشخاص، فاکتور چندردیفی خرید/فروش، برگشت کامل فاکتور و اصلاح موجودی.
- ثبت سفارش واردات، چک، دریافت/پرداخت پایه و گزارش مالی مدیریتی.
- سند دستی چندردیفی، افتتاحیه و تراز آزمایشی ۸ ستونی، گردش حساب با فیلتر.
- خروجی CSV و پشتیبان/بازیابی JSON.

## محدودیت‌های مهم
- داده‌های PWA و Android هنوز مستقل‌اند و همگام‌سازی واقعی بین دستگاه‌ها فعال نیست.
- ثبت سفارش واردات در PWA هنوز به رسید انبار و سند بهای تمام‌شده متصل نشده است.
- دریافت/پرداخت PWA هنوز گردش کامل سند خودکار و اتمیک مشابه Android ندارد.
- چرخه کامل چک، چندانباره، حواله، مغایرت بانکی، تسویه فاکتوربه‌فاکتور، دفاتر کل/معین/تفصیلی، صورت‌های مالی کامل، چاپ و بارکد هنوز تکمیل نشده‌اند.
- Release APK امضاشده با گواهی ثابت هنوز در CI تأیید نشده است؛ APK دیباگ را نباید نسخه انتشار نهایی تلقی کرد.

## ساخت Android
با JDK 17، Android SDK 35 و Gradle 8.9:
```bash
gradle testDebugUnitTest assembleDebug --no-daemon
```

خروجی Debug در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## انتشار PWA
PWA از مسیر `pwa/` ساخته و روی GitHub Pages منتشر می‌شود. پایگاه داده آن در مرورگر همان دستگاه ذخیره می‌شود؛ پاک‌کردن داده‌های سایت یا مرورگر بدون پشتیبان می‌تواند اطلاعات محلی را از بین ببرد.

## نکته عملیاتی
قبل از استفاده واقعی، از داده‌ها پشتیبان بگیرید و سناریوهای خرید، فروش، برگشت، دریافت/پرداخت، واردات و بازیابی را با حسابدار بررسی کنید. هیچ migration مخرب یا حذف اطلاعاتی نباید بدون پشتیبان و آزمون بازیابی انجام شود.
